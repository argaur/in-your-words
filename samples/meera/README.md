# Sample persona: Meera Iyer (fictional)

Every public surface of Voice Proof Desk uses this persona: the saved replay, the live demo's default input, the sample files and both demo videos. The real user's story bank never leaves his machine.

- `bank.md`: her dictated stories, 28 numbered items.
- `glossary.json`: words a dictation tool tends to mishear, with the fix.
- `do-not-send.json`: her own do-not-send list, as an example of the file format.

## Why she has these stories
Her bank is built so the demo shows every behaviour the judge must handle:
- A real AI evaluation with numbers (items 6 to 9), so the judge has numbers to check.
- A careful pilot caveat (items 9, 26), so an overclaim like "cut response time by 42% company-wide" gets cut.
- A failed launch (items 12, 13) and a gap she admits (item 25), so the tool must not turn them into wins.
- A career break (item 16) and no referrals so far (item 18), so the referral note has a real reason to exist.
- No people management (item 27), so "led a team of seven" gets cut.

## Rules for editing
- Keep her fictional. No real employer names, no real people, no facts from the real user's bank.
- If a demo needs a new behaviour, add a story item here. Never edit the output to fake it.
